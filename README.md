# 知间 · Between Pages

面向个人的本地学术阅读工作台。Next.js + React + TypeScript；书籍、进度、笔记、讨论和音频存入本机 SQLite / 文件目录。可以独立于 ChatGPT 运行。

## 本地启动

```bash
git clone https://github.com/liy001008-ship-it/read-talk-.git
cd read-talk-
zsh scripts/run.sh
```

也可以在 Finder 双击 `启动知间.command`。启动脚本默认使用生产服务；首次没有构建时会先构建。改动源码后请先重新运行 `npm run build`，开发调试使用 `npm run dev`。打开终端打印的地址，默认 **http://127.0.0.1:3000**。停止服务：终端按 Control-C。端口被占用时以终端实际地址为准。

启动脚本优先使用已安装的 Node；本机没有 Node 时可以使用 Codex 已下载的 Node 24 运行时。离开 Codex 后仍可运行，只要这个运行时目录仍在。迁移到其他电脑，安装 **Node.js 24 LTS**：

```bash
npm install
npm run db:migrate
npm run dev
# 生产模式
npm run build
npm start
```

服务绑定到回环地址，只供这台机器使用。不需要云数据库。移动端布局可以在本机浏览器设备模拟模式中使用；当前没有局域网访问和多用户认证，不能直接从手机访问本机服务。

## 开始阅读

1. 打开「书房」，拖入 EPUB / TXT / PDF，可批量导入。或打开应用原创的导读样章。
2. 左侧切换章节，中间阅读原文，右侧选择模拟学科教授与阅读模式。三栏边界可拖动，右上角可进入沉浸模式。
3. **点击原文段落**记录读到的位置；滚过的段落也会保存。选中同一段落中的文字可解释、翻译、高亮、批注或保存词汇。严格防剧透下，选文会把阅读边界推进到所选文字末尾。
4. EPUB 可在文本 / 原版视图切换；原版使用 epub.js，保存 CFI。PDF 使用 PDF.js 渲染实际页面；文本定位与实际文件页码一致。扫描 PDF 无文本层时会明确提示，仍能浏览原版。
5. 底部可选择本机系统朗读（免费，声音取决于操作系统）或 AI 语音。AI 音频分段生成、按内容与模型缓存；双教授讨论可用不同声音朗读。

## 连接 AI

进入右上角「设置」，填写自己的 API Key、Base URL 和模型。保存后测试连接；连接测试读取模型列表，不代表模型生成或 TTS 已通过验证。

默认值是可修改的配置示例：`gpt-4.1-mini`、`text-embedding-3-small`、`gpt-4o-mini-tts`。兼容服务需支持 Chat Completions、Embeddings、Audio Speech 相应接口。账号可用模型与收费以服务商为准。

也可复制 `.env.example` 为 `.env.local`。**不要使用 NEXT_PUBLIC_ 保存凭据**，不要将 `.env.local` 或 `data/` 提交到代码仓库。应用设置中的密钥经 AES-256-GCM 加密存入 SQLite，本机加密密钥位于 `data/.secret-key`，权限 0600。API 响应从不回传已保存密钥。本机账号本身有读权限，磁盘加密仍由 macOS 管理。

阅读、目录、书签、笔记、关键词搜索、观点记录、备份和导出不需要 API。模型生成、语义查询、向量索引、摘要与 AI 语音需要有效密钥。

## 研究功能

- 7 种模拟学科视角：中文文学、英美文学、哲学、历史学、艺术史、媒介理论、跨学科。不是现实教授身份。
- 快速解释、逐段精读、章节片段分析、苏格拉底讨论、批判阅读、中英翻译和手动阅读提问。
- 双教授讨论：分别回应、最多自动推进 4 轮、手动下一轮、用户插话、暂停 / 继续、保存纪要、双声 TTS。
- 跨书研究：选择书籍，按关键词或 Embedding 查询，生成带核验原文的报告；编辑、保存、继续研究和导出。
- 笔记区分个人观点 / AI 分析 / 外部资料 / 研究笔记。个人观点演变采用追加版本，历史时间与内容不可原地改写。
- 个人档案展示藏书、阅读记录、研究主题、概念关联、词汇和实际 API token 用量。按填写费率估算费用，不能替代账单。

## 防剧透与引用

严格模式在数据库查询、段落裁剪、语义候选排序、对话历史回放和提示词组装时限制可见范围，默认只有已读位置以前的原文。允许当前章节 / 全书必须由用户切换。

模型的来源 ID 与引文在服务端重新核验，只有逐字匹配当前可见原文的引用才显示为来源卡片。点击卡片定位原段落。未核验的模型背景知识不会被标为原文证据。模型仍可能误解文本；来源核验不等于学术结论正确。

## 索引、费用与取消

导入仅建立本地 FTS5 索引，**不会自动调用付费 API**。在「设置 → 全书知识索引」选择书籍，查看粗估输入量后明确启动向量索引或分批摘要。任务记录游标，支持暂停、错误重试和重启后续跑。相同文本与模型复用向量。向量以 JSON 存储 SQLite，余弦相似度在本机计算。

所有生成都限制最大输出 tokens、最近对话条数与原文字符预算。已提交给服务商的请求即使取消也可能产生费用。大规模索引粗估不是报价；TTS 费用不包含在聊天 token 估价中。

## 数据与恢复

默认 `data/between-pages.sqlite`，原书在 `data/books/`，缓存音频在 `data/audio/`。`DATA_DIR` 可更改位置，启动前设置，避免在两个进程间共用一个目录。

「设置 → 下载完整备份」导出 ZIP，包含数据库记录、原书和音频，**不含 API Key 或本机加密密钥**。恢复会替换书库与记录，恢复前自动保存旧库备份到 `data/backups/`。新电脑恢复后重新配置密钥。JSON / Markdown 是便于研究使用的档案导出，恢复请使用 ZIP。

首次启动执行 `migrations/001_initial.sql`，后续启动使用 `PRAGMA user_version` 检测版本，不重复建库。新增迁移应追加版本，不要修改已部署用户的数据文件。

## 验证

```bash
npm run typecheck
npm test
npm run build
npm run test:e2e
```

Playwright 默认使用 macOS 已安装的 Google Chrome；其他环境配置 `PLAYWRIGHT_CHROME_PATH` 为 Chromium 可执行文件路径。端到端测试每次在系统临时目录创建源码快照和全新书库，并运行独立生产服务，不操作个人 data/，不改写开发目录的类型文件，也不删除已有记录。测试会校验源码与已有生产构建一致；先运行 npm run build，再运行端到端测试。

测试样本由 `tests/fixtures.ts` 生成：真正的 EPUB ZIP、带文本层的两页 PDF 与中英 TXT，不是用扩展名伪装的文件。离线测试不将模型替身或系统朗读冒充 OpenAI 调用成功。

架构见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)，实际完成程度与待验收项见 [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md)。

## 当前边界

这是一个可扩展的本地个人应用版本，尚未覆盖需求里的全部高级能力：

- OCR 仅提供类型化扩展接口，没有可直接使用的 OCR 管线；DRM / 加密 EPUB 不支持。
- PDF 原版视图暂不提供可选的叠加文本层；选择、批注与引用跳转使用文本视图，页码保持实际一致。
- EPUB CFI 与提取段落之间采用文本匹配映射，复杂排版、脚注与重复段落可能需要切回文本视图定位；未建立逐字符 DOM 映射。
- 章节即时分析使用有界片段，不会假称已分析整章。后台摘要按段落、章节、全书递归归约，并可在研究工作台查看；尚无实体关系图、学习式重排序和百万段落级向量索引。
- 长对话使用最近轮次和相关个人笔记，尚无滚动模型摘要记忆；长期记忆检索目前是可溯源关键词查询，没有自动跨书兴趣画像。
- 双语由教授面板提供对照分析，尚无整章逐句对齐的双栏翻译排版。
- 系统朗读的进度按段落显示；变速从下一段生效。AI 音频支持段落跳转和段内进度，尚无连续节目文件导出。
- 扫描 / 密集排版 PDF 的正文阅读顺序取决于原文件文本层。单书 100 MB，备份压缩包 250 MB；不承诺超大型语料的性能。
- 没有提供参考截图，视觉按需求中的三栏、暖纸与阅读中心原则实现。
- 真实 AI 讲解、Embedding、TTS 的质量与在线集成需要有效 API Key 再验收；本次没有用户密钥。
